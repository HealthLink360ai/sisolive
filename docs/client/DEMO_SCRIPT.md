# SISO Live Demo Script

## 1. Open The Tool

Open https://sisolive.lspdedge.com/?fresh=1 and sign in with the approved demo account.

Suggested framing:

"This is the controlled pilot version of SISO Live. The goal is to show how employees can learn from approved Supplier Inclusion & Sustainability content, while admins can identify where the knowledge base needs improvement."

The `?fresh=1` link resets local onboarding state in the browser so the reviewer sees the first-time orientation flow. It can be used with the approved demo account; after orientation, admin users can still open the Admin dashboard from the learner experience.

## 2. Learner Experience

Start in the learner chat.

Ask:

- What is supplier inclusion?
- How does AbbVie define a diverse supplier?
- What are AbbVie's four pillars of supplier inclusion?

Point out:

- concise answer structure;
- confidence indicator;
- source filename;
- "Verified source match" label;
- helpful/not helpful feedback.

Suggested framing:

"The tool is not answering from general internet knowledge. It searches the approved SISO source material and generates a grounded answer with a visible source."

## 3. Safe Escalation

Ask:

- What is the capital city of Mars?

Expected result:

The tool escalates rather than inventing an answer.

Suggested framing:

"For unrelated or unsupported questions, the tool does not force an answer. It routes the user toward support instead."

## 4. Admin Dashboard

Open Admin dashboard.

Show:

- Active users;
- Total queries;
- Avg confidence;
- Escalation rate;
- Answered demand;
- Needs review.

Suggested framing:

"Answered demand shows what learners are successfully asking about. Needs review shows escalated or low-confidence topics that may need clearer source content."

## 5. Manage Documents

Open Manage docs.

Show:

- source sections indexed;
- searchable status;
- needs indexing filter;
- search health check.

Suggested framing:

"The admin can confirm whether source content is searchable and whether the AI services are connected before relying on the tool for a demo or pilot."

## 6. Feedback Loop

Open Feedback or explain the loop:

- users rate answers;
- admins review low-confidence topics and feedback;
- content owners improve approved materials;
- admins re-index;
- QA reruns the RAG evaluation.

Suggested framing:

"The system gets smarter because the approved knowledge base gets better, not because it blindly trains on user input."

## 7. Close

Recommended close:

"The current build is ready for a controlled pilot conversation. The next phase is enterprise hardening: SSO, audit controls, retention policy, monitoring, formal testing, and security review materials."
